## 🇧🇷 Sobre o Projeto

Website institucional e catálogo digital desenvolvido do zero para a **São Salvador**, marca especializada na produção de palmito de açaí premium e sustentável da Amazônia.

O projeto tem como objetivo apresentar a história e a procedência da marca, exibir a linha de produtos (Pote Família, Pote Clássico e caixas personalizadas), disponibilizar canais diretos de atendimento e um formulário para envio de currículos na seção "Trabalhe Conosco".

### 🛠️ Como foi desenvolvido

O site foi construído com foco em alta performance, código limpo e uma interface moderna (*dark theme*) totalmente responsiva para qualquer dispositivo:

* **React** — Estruturação da interface em componentes reutilizáveis.
* **TypeScript** — Tipagem estática para maior segurança e facilidade de manutenção.
* **Vite** — Ferramenta de build rápida e ambiente de desenvolvimento otimizado.
* **Tailwind CSS** — Estilização moderna e utilitária com foco em responsividade e consistência visual.

## 🇺🇸 About the Project

Institutional website and digital catalog built from scratch for **São Salvador**, a brand producing premium, sustainably harvested Amazonian açaí palm hearts.

The project showcases the brand’s origin and sustainable practices, highlights its product line (Family size, Classic size, and custom assorted boxes), provides direct contact channels, and features a career application form with resume attachment.

### 🛠️ How it was built

Developed with a strong focus on high performance, clean architecture, and a modern, responsive dark-themed UI:

* **React** — Component-based architecture for dynamic and reusable UI elements.
* **TypeScript** — Static typing for robust code quality and maintainability.
* **Vite** — Modern, fast build tool and development server.
* **Tailwind CSS** — Utility-first styling for layout responsiveness and clean visual design.
